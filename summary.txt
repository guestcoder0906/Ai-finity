I have successfully implemented all of your requests regarding community features, role management, and administrative capabilities. The application now supports robust community adventure sharing and moderation.

**Community Adventures & Metadata:**
*   **Customization:** Users can now set an optional custom name and description for their adventures before posting to the Community Hub.
*   **NSFW Content Handling:** A manual toggle has been added to mark posts as NSFW. I also implemented an automatic keyword detection system that will flag an adventure as NSFW automatically if explicit or violent terms are found in the prompt, narrative, or descriptions.

**Admin & Moderator Identity:**
*   **Role Setup:** "Chloe" has been properly initialized as the root Admin upon login.
*   **Identity Tagging:** Implemented visual identity badges for roles. Admins display a celestial-themed tag with glowing name elements. Moderators display a golden-themed tag. Both roles have an option in their profile settings to toggle off ("hide glow") their highlighted identity if they wish to remain discreet.

**Administrative Dashboard & Quota Control:**
*   **Admin/Mod Panel:** I have integrated a dedicated, secure dashboard directly inside the **Account Profile** tab (accessible from the identity bar). This panel is only visible to Admins and Mods.
*   **Action Granting:**
    *   **Moderators** can grant up to a maximum of 500 actions per user per day. This limit is strictly validated via Firestore security rules and backend enforcement.
    *   **Admins** have unrestricted access and can grant infinite (unlimited) actions to any user, as well as revoke that status.
*   **Perks & Promotions:** Both roles can grant permanent access to "Unlimited Saving" and "Community Posting" privileges to free tier players. Admins can further promote other players to Moderator status or demote them back to standard users (Mods cannot promote).

Everything is securely managed via Firestore role-based access control (RBAC), ensuring normal users cannot spoof roles or bypass grant limits.
